# Triage labels

Las skills usan cinco roles canónicos. Aplicá la etiqueta correspondiente
al clasificar un issue.

| Rol | Etiqueta en GitHub | Significado |
| --- | --- | --- |
| needs-triage | needs-triage | Pendiente de evaluación |
| needs-info | needs-info | Falta información del autor |
| ready-for-agent | ready-for-agent | Especificado y listo para un agente |
| ready-for-human | ready-for-human | Requiere implementación humana |
| wontfix | wontfix | No se realizará |

Para cambiar la nomenclatura, editá la columna «Etiqueta en GitHub».
